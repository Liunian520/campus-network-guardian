## v0.3.2 紧凑桌面界面

验证日期：2026-11-16。采用用户指定的 `.agents/skills/ui-ux-pro-max/SKILL.md`、已有 Fluent 2 配色和原生 Win32 交互规则。

- `cargo test --quiet`：82 项通过，3 项真实环境检查仍默认忽略。Release 构建无警告，`cargo fmt --check` 通过。
- 配色工具更新为当前实际使用的颜色对：38 项有门槛检查及 2 项信息报告通过；行内错误文字为 6.53:1。配色解析/计算的 3 项自检通过。
- 两页在 96/144/192 DPI 下完成正常、等待、异常及长网卡名预览；192 DPI 的超长状态 17 行可滚动到第 12 行，保留完整文字与复制能力。无空格的 225 字符 ASCII 网卡名在 96/192 DPI 下完整展开并通过文本一致性检查。
- 四种无效表单（缺网卡、缺账号、未同意 HTTP 风险、换账号但缺密码）均提供具体行内提示，焦点分别为 101/102/104/103，保留假账号和密码草稿。成功保存后的提示只说明设置已保存，不推断联网成功。
- 预览先复现缺少行内提示，再确认修复；另复现了短屏主动滚动被旧焦点拉回，以及 EDIT 的 32 位 -1 返回值零扩展导致单行状态出现滚动条。修复后 280 像素短窗滚动、单行隐藏滚动条、Tab 顺序、原生下拉框上下键、跨页草稿和托盘恢复均通过。
- 预览输入使用 `WM_SETTEXT/WM_GETTEXT` 访问实际原生控件；密码控件限制跨进程读取，因此仅检查已知假密码的长度。无效保存前核对全部假字段，保证在凭据/注册表事务前返回。早期工具调试曾对假账号触发一次凭据查找，未读取匹配密码或进行写入；已通过前置条件防止再次发生。
- 真实门户只读状态测试通过；正式 0.3.2 已替换原路径程序，随后状态为“校园网在线”，主标题为“校园网已连接”。真实进程收到隐藏启动、最小化、关闭到托盘后的双击回调均恢复面板；第二实例正常退出。此处验证回调处理，不代替鼠标到 Shell 的完整链路测试。
- 发布前后配置 SHA256 与 Run 自启动命令一致；没有重新写入凭据。正式实例为一个，无残留预览进程。旧二进制备份在 `target/release-backups/`。

- 复核未发现新增认证、凭据或托盘交互阻断问题。校验失败及跨页切换保留草稿；关闭到托盘仍按原有安全行为清空未保存的密码输入，已保存凭据保留。

虚构数据预览保存在 `previews/v0.3.2/`。本轮未做真实断线恢复、登录提交或重拨验收；系统高对比度、独立文本大小与真实读屏器仍沿用下文验证限制。

## 范围与限制

- 预览使用虚构网卡、账号和状态，没有启动网络工作线程，也没有点击保存、删除、检查或门户操作。
- 这次 UI 验收不包含主动断线、重新认证或运营商重拨测试。
- 没有宣称完成读屏器、Windows 独立文本缩放或真实系统高对比度模式的完整实机验证，也不是 WCAG 合规认证。
- 当前实现浅色主题及既有的系统高对比度原生回退，没有新增暗色主题。
