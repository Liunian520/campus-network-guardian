# 校园网守护设计规范

## 依据与适用范围

- UI UX Pro Max：`nextlevelbuilder/ui-ux-pro-max-skill`，安装修订 `e59ff376a41f7ca47b7541ad5c116495cbade3ee`，使用其中 `fluent-2` 风格条目、通用 UX 规则和交付检查表。
- [Fluent 2 色彩](https://fluent2.microsoft.design/color)、[Windows 字体层级](https://fluent2.microsoft.design/typography)、[布局](https://fluent2.microsoft.design/layout)。
- 实际技术栈是 Rust + Win32 原生控件与 GDI，不是 WinUI、WPF、网页或移动应用。保留原生键盘、输入法、密码粘贴与高对比度回退，不引入浏览器或远程字体。
- 使用场景是个人 Windows 电脑的轻量网络守护工具。界面只解释控制器的真实结果，不因界面呈现改变认证、重拨或凭据策略。

## 检索记录与选择

1. `desktop network monitoring utility --design-system`：返回营销网站的 Hero / Features / CTA，不能作为此桌面应用的规范。
2. 按技能要求缩小为 `Fluent 2 desktop utility --design-system`：仍然偏向营销网站，未持久化该不适用输出。
3. `Fluent 2 --domain style --full -n 1`：确切命中有效的 `fluent-2` 条目，适用于 Windows。采用其克制层级、语义颜色、统一圆角、平台交互与可见焦点规范。
4. 定向查询 `associated input labels`、`focus not obscured`，结合本地 quick-reference 及 pro-rules 复核标签、焦点、对比度和键盘顺序。

Win32 没有对应的 skill 实现栈条目。因此采用经过核对的通用 UX 与 Fluent 2 设计规则；不把其他框架的 API 或移动设备单位移植到程序中。

## 颜色与语义

颜色的代码来源统一为 `src/ui_theme.rs`。RGB 值在该处转换为 Win32 COLORREF，绘制代码使用语义名称。

| 角色 | RGB | 用途 |
|---|---|---|
| 主操作 | `#0F6CBD` | 每页唯一的主要按钮、选中导航、焦点 |
| 主操作悬停 | `#115EA3` | 悬停反馈 |
| 主操作按下 | `#0C3B5E` | 按下反馈 |
| 主文字 | `#242424` | 标题和正文 |
| 次文字 | `#424242` | 次要信息 |
| 辅助文字 | `#616161` | 提示、说明、版本 |
| 关键控件边界 | `#8A8886` | 输入框和次要按钮边界 |

实际完整颜色集以代码为准。普通文字与其实际背景至少 4.5:1；有意义的图标、控件边界及焦点至少 3:1。装饰性卡片分隔线不承担独立交互语义。

成功、注意和等待状态同时提供文字；颜色不作为唯一提示。普通原始状态保持完整，至少可通过键盘聚焦和滚动读取。

## 字体与间距

- 使用本机 Windows 字体；中文使用 Microsoft YaHei UI，避免下载不具备中文覆盖的网页字体。
- 标题、状态、正文、辅助信息具有固定角色；辅助文字采用 13 DIP，正文采用 14–15 DIP，不通过压缩字号解决溢出。
- 使用 4/8 DIP 网格，分组节奏采用 16/24/32 DIP。页内主内容保持统一左右对齐和内边距。
- 输入框、按钮和导航使用统一的圆角与焦点尺度；焦点至少 2 DIP，所有尺寸随系统 DPI 缩放。
- 状态主区保持紧凑，给当前网络和操作区保留空间。风险同意区保留完整文本，降低纯装饰色块的视觉重量。

### v0.3.2 紧凑桌面布局

- 本轮依据用户指定的 `.agents/skills/ui-ux-pro-max/SKILL.md`，定向 `form helper validation --domain ux` 命中提交反馈、关联标签和行内校验。桌面密度查询没有精确适用条目，密度调整来自现有 Win32 界面审查，不采用营销网页布局。
- 760 × 600 DIP 基准窗口；侧栏 168 DIP，内容左缘 192 DIP、右缘 736 DIP。页面标题 22 DIP，连接主状态 24 DIP，正文 14 DIP，辅助信息 13 DIP。
- 状态卡基准高 144 DIP，仅保留主状态及一处完整检查结果；较长结果按原生字体度量扩展，超长结果保留原生滚动与复制。不再显示重复状态徽标和“自动恢复”结论卡。
- 主按钮/次按钮统一高 40 DIP，间隔 16 DIP。设置入口由侧栏提供。网卡名称和网关各占独立信息行；过长网卡名在设置下拉框下完整展开。
- 设置分为校园网络、账号与密码、自动化三组，组距 16 DIP。风险同意采用首行原生复选框加完整风险说明；自启动使用标题与辅助说明。保存与删除操作对齐底部。
- 错误说明在表单顶部按实际文字高度展开，定位首个错误字段；失败保留输入，成功清空密码并显示“设置已保存”，连接结论仍由检查结果决定。用户主动滚动不被旧焦点拉回。

## 原生交互与性能

- 概览以“立即检查”为主要操作；设置以“保存并开始守护”为主要操作。删除密码采用低强调文本动作。
- 导航当前页有形状或文字标记，并在原生按钮名称中表达当前状态。
- 创建控件时保持“账号标签 → 账号输入 → 密码标签 → 密码输入”的关联顺序。
- 切页保留未保存输入，隐藏页不参与 Tab；焦点不被滚动或固定区域遮挡。
- 状态框保留完整文字和滚动，不能拦截 Tab；仅绘制完整文本行。
- 悬停、按下和聚焦反馈不改变几何位置。无需装饰性动画或后台逐帧重绘，减少动效时不存在需要等待的过渡。
- 关闭窗口回到系统托盘；更新程序保留配置、凭据和自启动路径。

## 交付验收

- 侧栏保留作者 Liunian520、GitHub 主页与“关于 · 版本 · MIT”入口，链接与关于均可通过键盘聚焦。学校定位明确为武汉理工大学，不使用学校官方标志或暗示官方发布。
- 短窗口侧栏使用更紧凑的导航和单行作者入口，避免页脚覆盖导航或离开客户区；窗口过短无法容纳时隐藏页脚并移走其焦点，托盘仍保留关于入口。

- 对比度工具从实际 Rust token 定义读取颜色，并验证普通、悬停、按下和焦点配对。
- 独立预览仅使用虚构网卡与账号，不启动网络线程、不读凭据、不修改注册表；检查后退出并清理托盘图标。
- 检查 96/144/192 DPI、短屏滚动、长状态文本、当前页标记、Tab 顺序和字段跨页保留。
- 重新编译后切换实际运行版本，确认版本、单实例、配置及自启动路径，并测量内存。
- 手机横竖屏、安全区等移动平台条目不适用。没有实现暗色主题，不宣称通过暗色主题验收；系统高对比度使用原生回退。
- Windows 独立“文本大小”设置与真实读屏器的完整验证尚未完成，不把 DPI 预览等同于这两项验证。
