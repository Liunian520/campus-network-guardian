## 本版更新

- 同时检查流年 App 和 GitHub 官方发布，选择版本号较高的稳定版。一个来源暂时不可用时，可以从另一个来源获取更新。
- 下载前测量可用线路，按网络状况和文件大小选择流年 App 的 CF CDN、GitHub 镜像或官方下载。达到 1 MiB 的文件可用 2–4 个线程分段下载，分段失败时会退回单线程。
- 更新前核对文件大小和 SHA-256。流年 App 提供安装 ZIP，程序解包后检查其中的安装器。同版 GitHub 发布可用时，进一步核对两边的安装器是否一致。
- 点击侧栏“检查更新”，可在应用内查看更新说明、版本、来源和进度。后台自动检查和静默升级仍可使用。

## 安装与使用

- 从流年 App 下载后，完整解压安装 ZIP，再运行其中的安装程序。GitHub 也提供单独的安装程序和便携 ZIP。
- 支持 Windows 10 1607 及更新版本和 Windows 11（x64）。安装使用当前 Windows 用户权限，可选择登录后自动启动。升级沿用已有配置。
